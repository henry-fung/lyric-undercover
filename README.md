# 歌词谁是卧底

面向线下聚会的手机网页游戏。网页只负责私密发题、记录淘汰和结算；演唱、讨论、投票在线下完成。

## 启动

1. 复制 `.env.example` 为 `.env`，填写邀请码、模型 API 密钥和模型名称。使用 OpenAI-compatible 服务时，同时设置 `OPENAI_BASE_URL`。
2. 在 Test conda 环境中安装依赖：`python -m pip install -e ".[dev]"`。
3. 启动：`uvicorn main:app --host 0.0.0.0 --port 8000`。
4. 让聚会参与者用同一局域网访问 `http://<主机IP>:8000`。

房主创建房间并设置卧底人数。每轮由房主选择主题或随机出题；录入线下投票淘汰的人后，可以生成下一轮。所有身份会在最终结算时公开。
